# site — plugin da usare

Per audit e correzioni SEO delle pagine usa il plugin **SEO Audit Kit**
(skill: seo-audit, seo-page-audit, seo-code-audit, seo-fix-plan).
Per hreflang/traduzioni, schema markup e link interni usa **SearchFit SEO**
(content-translation, schema-markup, internal-linking, technical-seo).
Il sito è multilingua (/<lang>/): ogni modifica va verificata in tutte le lingue.
